AI respiratory-sound classification

This website uses the trained ICBHI respiratory-sound prototype model. Put a converted model at:

The browser-ready trained ICBHI prototype model is embedded in this page for simple GitHub Pages deployment.

The website now matches the trained model preprocessing: 4 kHz mono audio, 2-second center crop/pad, peak normalization. A model file alone is not enough if its scaler, feature order, or preprocessing pipeline is different.

The browser runs the trained model locally with TensorFlow.js; no audio is uploaded to a server.
