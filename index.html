How to enable real AI predictions

This HTML file is designed so you can later add a TensorFlow.js model without rebuilding the website. Put a converted model at:

model/model.json and its corresponding .bin weight file(s).

The model must be trained for the exact input representation used by its JavaScript preprocessing. A model file alone is not enough if its scaler, feature order, or preprocessing pipeline is different.

TensorFlow.js loads browser models with tf.loadLayersModel(); converted Keras models use TensorFlow.js's model format.
